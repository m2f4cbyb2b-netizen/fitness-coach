Dein Ganzkörperplan mit smarten Steigerungsempfehlungen.

Heutiger Trainingsplan

Trage Gewicht (kg), Wiederholungen, Kraftreserve (RIR: 0 = keine, 2 = noch zwei Wiederholungen möglich, 3+ = mindestens drei) und absolvierte Sätze ein. Bei Körpergewichtsübungen kann das Gewicht 0 bleiben. Die Empfehlungen sind Richtwerte; verwende nur tatsächlich verfügbare Gewichtsstufen.

Kraftentwicklung

Angezeigt wird das höchste dokumentierte Trainingsgewicht je Einheit. Bei gleichem Gewicht zeigen mehr Wiederholungen ebenfalls einen Fortschritt.

Datensicherung

Deine Daten werden nur in diesem Browser auf diesem Gerät gespeichert. Bei gelöschten Browserdaten können sie verloren gehen.

Auf dem Smartphone

Für ein dauerhaftes Startbildschirm-Symbol diese Datei als HTTPS-Website veröffentlichen und anschließend im Smartphone-Browser „Zum Home-Bildschirm“ wählen. Eine lokal geöffnete HTML-Datei lässt sich nicht auf jedem Smartphone zuverlässig als App installieren.

Wichtig: Trainingsdaten bleiben nur im jeweiligen Browser. Vor Browserwechsel oder Gerätewechsel bitte ein Backup herunterladen. Ohne Server gibt es keine automatische Synchronisierung.

So coacht dich die App

Wenn du alle geplanten Sätze am oberen Ende des Wiederholungsbereichs schaffst und in jedem Satz mindestens 2 Wiederholungen Reserve (RIR) dokumentierst, empfiehlt sie ein konkretes Zielgewicht (kleine, gerundete Steigerung). Wenn du unter dem Mindestziel bleibst, empfiehlt sie, das Gewicht zu halten oder zu reduzieren. Das ist eine regelbasierte Orientierung, keine individuelle medizinische Betreuung.
